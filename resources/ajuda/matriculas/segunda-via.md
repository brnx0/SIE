## O que é

Tela para reemitir o **Comprovante de Matrícula** de um aluno já matriculado. O comprovante é gerado em PDF e abre em uma nova aba, pronto para imprimir ou salvar.

## Como acessar

Menu **Matrículas → 2ª Via Comprovante**.

## Passo a passo

1. Selecione o **Ano Letivo**.
2. No campo **Aluno**, busque por nome, matrícula ou CPF e selecione o aluno.
3. Clique em **Buscar Matrícula**.
4. O comprovante abre automaticamente em uma nova aba. Use **Abrir novamente** caso precise reabri-lo.

## Campos principais

- **Ano Letivo**: obrigatório; define de qual ano será emitido o comprovante.
- **Aluno**: obrigatório; selecionado a partir da busca.

## Avisos comuns

- **Sem matrícula ativa**: o sistema só emite a 2ª via se o aluno tiver matrícula ativa no ano letivo selecionado. Caso contrário, aparece o aviso de que não há matrícula ativa nesse ano.
- **Nova aba bloqueada**: se o comprovante não abrir, verifique se o navegador está bloqueando janelas (pop-ups) para o sistema e libere.
- **Ano correto**: um aluno pode ter matrículas em anos diferentes; confira sempre o ano letivo antes de emitir.
